# Fichiers archivés

Ces six fichiers (`permissions.js`, `financial-model.js`, `import-model.js`, `event-model.js`, `tenant-model.js`, `search-model.js`) étaient des catalogues de référence créés au fil des sessions de conception. Ils n'ont jamais été chargés par aucune page — aucune logique exécutable, jamais utilisés.

Retirés lors de l'audit stratégique du [docs/AUDIT_STRATEGIQUE.md](../../../docs/AUDIT_STRATEGIQUE.md) : ils recopiaient en JS des listes déjà écrites dans les documents Markdown (`docs/SECURITE.md`, `FINANCE.md`, `IMPORT.md`, `EVENEMENTS.md`, `MULTI_TENANT.md`, `DASHBOARDS_RECHERCHE.md`), sans valeur fonctionnelle réelle, avec un risque de dérive par rapport à ces mêmes documents.

Conservés ici (archivés, pas supprimés) au cas où leur contenu serait utile comme point de départ lors de l'écriture du vrai backend — mais ne doivent pas être réintégrés tels quels sans revérification.
